Phase 2: Location Expansion (Week 3-4)

City-Specific Landing Pages

Create 6 location pages targeting nearby cities without dedicated dermatology competitors:

/locations/american-fork-dermatologist/
/locations/saratoga-springs-dermatologist/
/locations/eagle-mountain-dermatologist/
/locations/pleasant-grove-dermatologist/
/locations/draper-dermatologist/
/locations/highland-dermatologist/

Each Location Page Needs:

  1. H1: "Dermatologist Serving [City], UT"
  2. Intro: Personalized copy about serving that community
  3. Distance/Directions: "Just X minutes from [City]"
  4. Services list: Link to main service pages
  5. Map embed: Showing route from that city
  6. LocalBusiness schema: With areaServed for that city
  7. Click-to-call CTA: Prominent phone number

Why This Works:

  • Utah Valley Derm only has 3 locations
  • These 6 cities have 200K+ combined population
  • No one is targeting "dermatologist eagle mountain" specifically
  • Each page = new keyword opportunity

Phase 4: Provider Authority (Week 7-8)

Individual Provider Pages

Each doctor/PA/NP gets their own page:

/providers/dr-david-smart/
/providers/dr-eric-smart/
/providers/elizabeth-harding/
/providers/carrie-jackman/
/providers/lindsey-smart-smith/
/providers/caitlin-brewer/

Each Provider Page Needs:

  1. Physician schema markup (critical for Google)
  2. Credentials: Board certifications, education
  3. Specialties: What they focus on
  4. Professional photo: High quality
  5. Personal bio: Human, approachable
  6. Reviews/testimonials: If available
  7. Book with this provider CTA

Why Provider Pages Matter:

  • "Dr. David Smart dermatologist" = branded search
  • Builds E-E-A-T (Experience, Expertise, Authority, Trust)
  • Physician schema appears in Google Knowledge Panel
  • Patients research doctors before booking

Phase 5: Content Engine (Ongoing)

Blog Strategy

Frequency: 2 posts/month minimum

Topics to prioritize:

  1. "When to see a dermatologist for [condition]"
  2. "Best [treatment] options in Utah"
  3. "How to prepare for your skin cancer screening"
  4. Seasonal: "Summer skincare tips for Utah sun"
  5. FAQ expansions: Turn common questions into posts

Content format:

  • 800-1,200 words
  • Include at least 1 image
  • Internal links to service/condition pages
  • FAQ schema for question sections
  • Author attribution (builds E-E-A-T)

Technical SEO Checklist

On-Page (Every Page)

  • Unique title tag (60 chars max)
  • Meta description (155 chars max)
  • H1 contains target keyword
  • Internal links to related pages
  • Image alt text with keywords
  • Click-to-call phone number
  • Schema markup appropriate to page type

Site-Wide

  • XML sitemap at /sitemap.xml
  • HTML sitemap for users
  • Robots.txt allowing all important pages
  • Canonical URLs set
  • 301 redirects from old URLs (if migrating)
  • Google Search Console verified
  • Google Analytics 4 installed
  • Google Business Profile linked

Performance

  • Page speed: Mobile score 80+
  • Largest Contentful Paint < 2.5s
  • Cumulative Layout Shift < 0.1
  • First Input Delay < 100ms
  • Images compressed (WebP preferred)
  • CSS/JS minified
