Missing for Maximum SEO Impact

1. Location Pages (CRITICAL)

Create dedicated pages for each nearby city:

  • /locations/lehi-dermatologist.html
  • /locations/american-fork-dermatologist.html
  • /locations/saratoga-springs-dermatologist.html
  • /locations/eagle-mountain-dermatologist.html
  • /locations/pleasant-grove-dermatologist.html
  • /locations/draper-dermatologist.html

Each page should have:

  • H1: "Dermatologist in [City], UT"
  • Local schema markup
  • Driving directions from that city
  • Services available
  • Unique content about serving that community

2. Condition Pages (HIGH VALUE)

  • /conditions/acne-treatment-lehi.html
  • /conditions/eczema-dermatitis.html
  • /conditions/psoriasis-treatment.html
  • /conditions/rosacea.html
  • /conditions/skin-cancer.html
  • /conditions/mole-removal.html
  • /conditions/warts-removal.html

3. Provider Individual Pages

Each provider needs their own URL:

  • /providers/dr-david-smart.html
  • /providers/dr-eric-smart.html
  • /providers/elizabeth-harding-np.html
  • etc.

With Physician schema markup on each.

4. Schema Markup Checklist

  • LocalBusiness schema on every page
  • MedicalBusiness schema on homepage
  • Physician schema on provider pages
  • FAQPage schema on FAQ
  • Service schema on service pages
  • Review/AggregateRating if reviews available

5. Technical SEO

  • XML sitemap generation
  • Robots.txt
  • Canonical URLs
  • Open Graph tags
  • Twitter cards
  • Google Business Profile link
